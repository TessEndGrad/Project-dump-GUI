# 📦 Project-dump-GUI

> **Скрипт для парсинга всего вашего проекта в `.txt` файл для дальнейшего использования в нейросетях**

---

## 🚀 О проекте

**Project-dump-GUI** — это удобный инструмент с графическим интерфейсом, который собирает всю структуру и содержимое вашего проекта в единый `.txt` файл. Идеально подходит для передачи контекста в большие языковые модели (ChatGPT, Claude, Gemini и др.) без необходимости копировать файлы вручную.

---

## ✨ Возможности

- 📁 **Рекурсивный обход** — сканирует все файлы и папки проекта
- 🖥️ **Графический интерфейс** — никакой командной строки, всё интуитивно
- ⚡ **Быстрый экспорт** — один клик, и дамп готов
- 🤖 **Оптимизировано для AI** — структура вывода удобна для нейросетей
- 🔧 **Гибкие настройки** — фильтры файлов, исключения, выбор директорий

---

## 📋 Как использовать

1. Запустите приложение
2. Выберите папку с вашим проектом
3. Настройте фильтры (при необходимости)
4. Нажмите **«Экспорт»**
5. Получите готовый `.txt` файл и используйте его в любой нейросети
